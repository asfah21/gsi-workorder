# Frontend Instructions

Sebelum mengubah UI di folder ini:

1. Baca `docs/Frontend UI Guidelines.md`.
2. Gunakan `PageHeader`, `SearchInput`, `FilterBar`, dan komponen `components/ui` yang sudah ada.
3. Jangan membuat ukuran search, input, select, button, atau page title baru per halaman.
4. Semua modal popup wajib berada di tengah layar, memakai `SheetContent` yang sudah terpusat. Jangan membuat side sheet kanan untuk form/detail.
5. Referensi visual: https://demos.shadcndashboard.dev/?mode=dark
6. Selesai hanya jika `npm run lint` dan `npm run build` lulus, serta layout dicek di mobile dan desktop, dark dan light.
